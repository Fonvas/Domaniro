Questions

Where does the Domain Score come from?

Domaniro's Domain Score is based on OpenPageRank, an open web-graph-based PageRank system. Domaniro also displays OpenPageRank's Global Rank and Referring Domains data.

What does the Domain Score tell me?

Domain Score provides a quick way to gauge a domain's strength within the OpenPageRank web graph. Higher scores indicate stronger overall link authority within that dataset.

What is Global Rank?

Global Rank shows the domain's position in the OpenPageRank global ranking. A smaller rank number represents a higher position.

What are Referring Domains?

Referring Domains is the number of distinct domains that link to a website. Multiple links from the same domain count as one referring domain.

Does Pro auto-renew or bill monthly?

Pro is a single one-time purchase. There is no recurring subscription or monthly billing.

What data does Domaniro collect?

Domaniro uses the domain of the page being checked for a metric lookup. The extension does not need full page content or browsing history to provide domain metrics. See the full privacy policy .
