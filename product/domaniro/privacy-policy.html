Privacy Policy — Domaniro

Summary

Domaniro is a Chrome extension that displays domain metrics while you browse. It does not require an account and does not collect personal information for user profiling or advertising.

Domaniro uses the domain name of the website being checked to retrieve Domain Score, Global Rank, and Referring Domains data. This page explains what information the extension handles, why it is used, and where it is processed.

What data Domaniro processes

When Domaniro checks a website, it uses the website's domain name (hostname), such as example.com.

The domain is used to request the following metrics:

  • Domain Score
  • Global Rank
  • Referring Domains

Domaniro does not need the full page URL, URL query parameters, page content, form data, or browsing history to provide these domain metrics.

How domain lookups work

When a domain lookup is required, Domaniro sends the domain name to our scoring backend. The backend checks its cache and, when necessary, requests metric data from OpenPageRank.

OpenPageRank provides the underlying web-graph data used by Domaniro for its Domain Score, Global Rank, and Referring Domains metrics.

Our backend may temporarily cache metric results to reduce repeated requests and improve response speed. Cached metric results are automatically deleted after 24 hours.

What we do not collect

Domaniro does not intentionally collect or maintain:

  • Names, email addresses, or other personal profile information
  • User accounts or persistent user identifiers
  • Browsing history
  • Web page content
  • Form inputs or submitted form data
  • URL query parameters or full page URLs for metric lookups
  • Advertising profiles or cross-site tracking identifiers

Domaniro does not use browsing activity to build advertising profiles or track individual users across websites.

Local storage

Domaniro uses chrome.storage.local to store recently retrieved domain metrics on your device.

Local cached data may include the domain name and its retrieved metric results, such as Domain Score, Global Rank, and Referring Domains.

This cache is used to reduce repeated network requests and make previously checked domains load faster. Cached entries are automatically expired after 24 hours.

Local storage can also be removed by uninstalling the extension or clearing the extension's stored data through Chrome.

Server-side processing

Domain lookup requests are processed through our backend infrastructure. We use this backend to cache metric results, communicate with the OpenPageRank API, and return the requested metrics to the extension.

Standard infrastructure and security logs may be generated by the hosting and network services used to operate the backend. These logs are used for purposes such as service reliability, security, abuse prevention, and troubleshooting.

Domaniro does not use these technical logs to create user profiles or track individual browsing activity.

Permissions

Domaniro requests browser permissions only where they are needed to provide its domain-metric features.

  • storage — Used to cache recently retrieved domain metrics locally on your device.
  • tabs — Used to identify the active tab's URL so Domaniro can determine the domain being checked and display the corresponding metrics.
  • Host permission for the scoring service — Used to send domain lookup requests to our backend and retrieve metric data.

Google and Bing search results

When Domaniro is enabled on Google or Bing search results, the extension reads the domains associated with organic search results in order to display Domain Score badges beside them.

Domaniro uses these domains to retrieve their metrics. It does not need to collect or store your search history, search queries, or the content of the search results for this feature.

Third-party data provider

Domaniro uses data provided by OpenPageRank, operated by Keywords Everywhere.

OpenPageRank is an external service and has its own terms and privacy practices. Its processing of API requests is governed by its own policies.

Pro license

Domaniro Pro is provided through a one-time purchase and does not require a recurring subscription.

If you activate Pro using a license key, the license key may be processed by the licensing system solely for the purpose of validating and maintaining access to Pro features.

Domaniro does not use Pro license information for advertising or behavioral tracking.

Children's privacy

Domaniro is a general-purpose browser extension and is not specifically directed toward children.

Changes to this policy

We may update this Privacy Policy when the extension's features, data practices, or applicable requirements change.

When this policy is updated, the "Last updated" date at the top of this page will be changed accordingly.
